CAMPUS LOST & FOUND - SIMPLE PROTOTYPE

WHAT IT DOES
1. Shows sample lost/found reports.
2. Searches reports by item name, description, category, type or location.
3. Lets a student submit a Lost or Found report.
4. Saves newly submitted reports in this browser using localStorage.

HOW TO OPEN IN VS CODE
1. Extract this ZIP file.
2. Open Visual Studio Code.
3. Select File > Open Folder.
4. Select the extracted Campus_Lost_and_Found_Prototype folder.
5. Open index.html.
6. Install the "Live Server" extension if it is not already installed.
7. Right-click index.html and select "Open with Live Server".
8. Your browser should open the prototype.

HOW TO TEST
- Search for "blue", "library", "calculator" or "electronics".
- Submit a sample Lost or Found report.
- Search for the newly submitted item.
- Refresh the page; the report should remain in the same browser.

IMPORTANT LIMITATIONS
- This is a front-end classroom prototype, not a production system.
- localStorage is browser-specific and is not a shared database.
- Do not enter real sensitive personal information.
- A real deployment would need authentication, a secure backend, database,
  access controls, image upload validation and privacy safeguards.
